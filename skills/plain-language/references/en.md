# English guide

Use this guide together with the core rules in [SKILL.md](../SKILL.md). It draws on ASD-STE100 Simplified Technical English and ISO 24495-1. It follows the principles only and does not claim STE compliance.

## Sentences

- Keep most sentences under 20 words. Use 25 as a hard limit for descriptions.
- Use simple tenses where they say the same thing: "I fixed the test", not "I have fixed the test". Keep the present perfect when it carries meaning the simple past loses, for example "the job has finished" (and the output is ready now), or a hedge like "may have failed".
- Do not drop words to save space. "Files not backed up will be lost" hides which files. Write "Files that you did not back up will be lost".
- Keep noun stacks to three words. "the request retry backoff timeout setting" becomes "the timeout setting for retry backoff".
- Do not use semicolons. Split the sentence instead.

## Words to replace

| Instead of | Write |
| - | - |
| utilize, leverage | use |
| perform an analysis of | analyze |
| make a decision | decide |
| in order to | to |
| due to the fact that | because |
| at this point in time | now |
| in the event that | if |
| prior to | before |
| subsequent to | after |
| a number of | some, several, or the exact number |
| is able to | can |
| facilitate | help, allow |
| commence | start |
| it should be noted that | (delete it) |

## Phrasal verbs

A two-word verb can mean something its parts do not predict. Prefer the single verb when one exists.

| Instead of | Write |
| - | - |
| spin up | start |
| reach out | contact |
| dive into | read, examine |
| kick off | start |
| circle back | return to |
| figure out | find, work out what |
| set up | configure, create |

Keep a phrasal verb when it is the established technical term and the single verb would be less exact: "log in", "roll back", "check out a branch".

## Marketing words

Delete words that claim quality without showing it: seamless, robust, powerful, cutting-edge, effortless, blazing-fast, best-in-class. If the claim matters, replace the word with the measurement: "starts in 40 ms", not "blazing-fast".

## Hedges

Keep the strength of the original hedge: "may", "might", "usually", "likely" stay as they are. Do not stack them: "it could potentially perhaps help" becomes "it may help".
